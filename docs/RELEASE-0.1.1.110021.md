# SkysTerrainSmoother 0.1.1.110021

Snow blocks and packed ice now receive matching slabs, steps and corners in
new terrain. Grass pieces match snowy terraces through the updated content
mods. This release also includes the level selector in Mods > Config, level 3
as the default for new configurations, and better handling of foliage and
narrow mountain ledges. Existing terrain stays unchanged.

Back up your world before updating. Install the main jar on the client and
server. Saved pieces retain their materials and orientations; new smoothing
applies only to newly generated chunks.
